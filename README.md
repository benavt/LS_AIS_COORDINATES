# LS AIS atlas coordinates

This repository holds the native coordinate files that the [LS AIS structure clustering atlas](https://benavt.github.io/LS_AIS/) loads on demand for the CDK2–DOC1, CDK2–DOC1R and CDK2 monomer cohorts.

Files are compressed individually with gzip. After decompression, each file matches the model's native SHA-256 in `manifest.json`. Model generation and analysis information is presented in the atlas. The full and trimmed CDK2–DOC1 views use the same native coordinate files.
